# 先干 — AI 短视频创作助手

做短视频最难的不是拍摄，而是"拍什么"和"怎么写"。

「先干」帮你解决从选题到发布的全流程：选题 → 设计 → 写脚本 → 审核，每一步都有 AI 陪你走。不需要任何经验，跟着提示回复就行。

---

## 指令一览

| 指令 | 做什么 | 你会拿到什么 |
| :--- | :--- | :--- |
| `/先干 选题` | 挑选题、起标题 | 3 个选题方案 + 9 个标题 |
| `/先干 参考` | 拆解爆款视频 | 爆款结构分析 + 改造建议 |
| `/先干 设计` | 规划视频节奏 | 分段设计 + 情绪曲线 + 画面声音方案 |
| `/先干 脚本` | 写分镜脚本 | 逐镜头的画面、台词、BGM、字幕 |
| `/先干 审核` | 发布前体检 | 违禁词检查 + 完播率预估 + 发布建议 |
| `/先干 素材库` | 查看灵感素材 | 情绪 × 形式 × 场景 三大元素库 |

---

## 使用流程

输入 `/先干 选题` 开始，AI 会一步步问你问题，你只需要回答就好。每个环节结束后回复「继续」，自动进入下一步。

```
/先干 选题 → 确定选题和标题
     ↓ 回复「继续」
/先干 设计 → 规划视频结构和节奏
     ↓ 回复「继续」
/先干 脚本 → 生成可以直接拍的分镜脚本
     ↓ 回复「继续」
/先干 审核 → 检查合规 + 发布建议
```

> 如果你有想参考的爆款视频，可以在选题之后加一步 `/先干 参考`，把链接或文案丢给 AI 拆解。

## 各环节详细说明

### 1. 选题标题

AI 会通过 4 轮对话帮你找到选题：

| 步骤 | AI 会问你 | 你需要做的 |
| :--- | :--- | :--- |
| 第 1 轮 | 你想做什么行业？ | 回答行业，比如"美妆"、"职场"、"美食" |
| 第 2 轮 | 展示素材库，让你挑元素 | 选情绪 + 形式 + 场景的组合（如 A2+B1+C2） |
| 第 3 轮 | 视频多长？发哪个平台？ | 回答时长、平台、目标观众 |
| 第 4 轮 | 生成 3 个选题方案 | 挑一个你最喜欢的 |

**素材库是什么？** 就是三组"配料"，你从每组选一个，组合出选题方向：

| 元素库 | 内容 | 举例 |
| :--- | :--- | :--- |
| **A 情绪** | 你想让观众产生什么感受 | 好奇、共鸣、焦虑、反转、实用、搞笑、认同、争议 |
| **B 形式** | 你打算用什么方式拍 | 口播、实拍、混剪、图文、剧情、访谈、测评、挑战 |
| **C 场景** | 你想讲什么类型的故事 | 行业痛点、成功案例、踩坑避雷、热点、对比、攻略、榜单 |

> 比如选 `A2 共鸣` + `B1 口播` + `C2 成功案例`，就是"用口播分享一段真实经历"。

---

### 2. 内容参考

把你觉得不错的视频链接或文案发给 AI，它会帮你做三层拆解：

| 层级 | 看什么 | 举例 |
| :--- | :--- | :--- |
| 表面层 | 时长、画面风格、标题写法 | 30 秒竖屏，快节奏剪辑，标题用了数字 |
| 结构层 | 内容怎么组织的 | 前 3 秒抛问题 → 中间给方法 → 结尾引导关注 |
| 心理层 | 为什么能火 | 利用了"损失厌恶"——不看就亏了 |

拆完之后会给出改造建议：哪些可以直接用，哪些需要变形，哪些可以升级超越。

---

### 3. 短视频设计

确定了选题之后，AI 帮你规划视频的节奏和画面。核心产出是**情绪曲线**和**分段设计**。

**情绪曲线**就是观众看视频时的情绪变化节奏：

| 曲线类型 | 节奏特点 | 适合什么内容 |
| :--- | :--- | :--- |
| 冲击型 | 开头就炸，后面解释 | 揭秘、反转、热点 |
| 攀升型 | 越看越燃，最后高潮 | 逆袭故事、挑战 |
| 过山车型 | 反复起伏，停不下来 | 剧情、搞笑 |
| 阶梯型 | 一个接一个干货 | 教程、攻略 |

每个时间段都会标注：这几秒画面拍什么、说什么、配什么音乐。

---

### 4. 脚本生成

根据设计方案，生成可以直接拿去拍的分镜脚本。格式大概长这样：

| 镜号 | 时间 | 画面 | 台词 | 字幕 | BGM/音效 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 0-3s | 人物面对镜头，表情严肃 | "你知道吗？90%的人都在犯这个错" | 同台词 | 紧张鼓点 |
| 2 | 3-8s | 切到产品特写 | "就是这个东西，我亲测了一个月" | "亲测一个月" | BGM 渐入 |
| ... | ... | ... | ... | ... | ... |

几个硬规则：
- 前 3 秒必须有冲击力
- 每句台词不超过 20 个字
- 每 15 秒至少一个情绪触发点
- 结尾有明确的行动引导（点赞/收藏/关注）

---

### 5. 脚本审核

发布前的最后一道关。AI 会做四件事：

| 检查项 | 具体内容 |
| :--- | :--- |
| 合规检查 | 扫描违禁词和敏感表达，给出替换建议 |
| 质量评分 | 7 个维度打分：开头吸引力、信息密度、节奏、情绪等 |
| 完播率预估 | 预判观众能看到第几秒，找出流失风险点 |
| 发布建议 | 推荐封面风格、发布时间、话题标签 |

**常见违禁词替换参考：**

| 原词 | 替换为 | 原因 |
| :--- | :--- | :--- |
| 最好 / 第一 / 顶级 | 强烈推荐 / 亲测好用 | 避免极限词限流 |
| 保证有效 / 绝对能赚 | 亲测不错 / 值得一试 | 避免虚假承诺 |
| 赚钱 / 暴富 | 变现 / 提升收入 | 避免敏感财务词 |
