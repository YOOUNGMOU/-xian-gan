# 先干

AI 短视频创作助手，覆盖从选题到发布的完整流程。

## 这个 Skill 能做什么

「先干」帮你解决短视频创作中最难的部分：想选题、写文案、排节奏、查合规。你不需要任何创作经验，跟着 AI 的提问一步步回答就行。

### 核心功能

- **选题标题** — 通过互动式问答，从爆款素材库中组合出选题，生成多个标题方案
- **内容参考** — 拆解爆款视频的结构和套路，给出差异化改造建议
- **视频设计** — 规划视频节奏、情绪曲线、画面和声音方案
- **脚本生成** — 输出可以直接拍的分镜脚本（画面、台词、BGM 逐镜头标注）
- **脚本审核** — 违禁词检查、完播率预估、发布时间和话题推荐

### 爆款素材库

内置三组创作元素，自由组合生成选题方向：

| 元素库 | 内容 |
| :--- | :--- |
| A 情绪 | 好奇、共鸣、焦虑、反转、实用、搞笑、认同、争议 |
| B 形式 | 口播、实拍、混剪、图文、剧情、访谈、测评、挑战 |
| C 场景 | 行业痛点、成功案例、踩坑避雷、热点、对比、攻略、榜单 |

## 快速开始

输入 `/先干` 查看总览，或直接开始创作：

```
/先干 选题
```

AI 会依次问你：行业 → 元素选择 → 视频参数 → 生成选题。每个环节结束后回复「继续」自动进入下一步。

### 完整流程

```
/先干 选题  →  确定选题和标题
/先干 参考  →  拆解爆款视频（可选）
/先干 设计  →  规划视频结构和节奏
/先干 脚本  →  生成分镜脚本
/先干 审核  →  合规检查 + 发布建议
```
